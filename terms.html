2. Description of Service

AttendEase is a personal academic management tool that helps students:

  • Track daily class attendance (Present, Absent, Late, Cancelled).
  • Calculate bunk budgets and safe-skip thresholds based on college minimum attendance criteria.
  • Manage timetables, assignments, exams, and holidays.
  • Optionally auto-mark attendance via background location proximity detection.
  • Optionally sync data to the cloud and join Social Squads with friends.
